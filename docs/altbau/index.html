Vermassungen

Länge: 2 Punkte. Winkel: Anfang, Scheitel, Ende. Fläche: mindestens 3 Punkte derselben Ebene, dann abschliessen.

Esc bricht ab, Enter schliesst eine Fläche. Messungen beziehen sich auf die rekonstruierte Geometrie. Speichern sichert sie separat als JSON; das IFC wird nicht verändert.
