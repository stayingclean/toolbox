# Checkliste Unterlagen

## Für Stellenbewerbungen
- [ ] lebenslauf.pdf (aktuell, ohne AHV-Nummer)
- [ ] Arbeitszeugnis Denner
- [ ] Arbeitszeugnis Coop
- [ ] Diplom EFZ
- [ ] Zertifikat Kassenverantwortliche
- [ ] Bestätigung Arbeitstraining (falls verlangt)
- [ ] Foto (freiwillig)

## Für Wohnungsbewerbungen
- [ ] Betreibungsauszug (nicht älter als 3 Monate)
- [ ] Kopie ID (erst beim Vertrag, nicht mit der Anfrage)
- [ ] Lohn- oder Einkommensnachweis
- [ ] Referenz bisheriger Vermieter oder Institution
- [ ] Haftpflichtversicherung (Nachweis oder Offerte)

## Nicht in diesen Ordner
- AHV-Nummer, IBAN, Passwörter: gehören nicht hierher (Claude liest alles in diesem Ordner).
